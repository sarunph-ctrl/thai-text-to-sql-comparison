### รันสด

พิมพ์คำถามแล้วกดเปรียบเทียบ เรียก IntelSphere หนึ่งครั้งและใช้ quota
หน้าเว็บส่งไป `/compare` ซึ่งทำให้สองวิธีอ่าน snapshot ฐานข้อมูลเดียวกัน
ป้าย "รันสด" แสดงหลังได้รับผลจริง ไม่ใช้ผลเก่ามาแทนเมื่อ API ล้มเหลว
กดปุ่มตัวอย่างจะเปลี่ยนข้อความเท่านั้น ต้องกดเปรียบเทียบเองจึงเรียกโมเดล

### ผลบันทึก

เลือกคำถามจากรายงาน Sprint 2 แสดงคำตอบ SQL เวลา Token และคะแนนของครั้งนั้น
ช่องคำถามอ่านอย่างเดียว เพื่อไม่ให้แก้คำถามแล้วดูเหมือนผลเก่าเป็นคำตอบของคำถามใหม่
ไม่เรียกโมเดลซ้ำ ป้ายระบุวันที่บันทึกชัดเจน
คะแนนเทียบอ้างอิงในโหมดนี้เป็นคะแนนของ snapshot ตอนทดลอง ไม่ใช่ฐานข้อมูลปัจจุบัน

## คำถามและคำตอบที่ต้องอธิบายเองได้

### ทำไมยอดขายเป็น 1250?

ออเดอร์ paid ในกันยายน 6 รายการมีมูลค่า `220 + 200 + 200 + 250 + 260 + 120 = 1250`
ข้อมูล cancelled 1850, pending 600 และรายการก่อน/หลังเดือนต้องไม่นับ
เปิด Schema & ข้อมูล แล้วโหลด orders กับ order_items เพื่อตรวจทีละรายการ
ใช้ `unit_price` ในรายการขาย ไม่ใช้ราคาปัจจุบันของสินค้า

### ทำไมคงเหลือปากกาในคลังหลักเป็น 131?

`100 ตั้งต้น + 50 รับเข้า − 19 จ่ายออก = 131`
ผลคงเหลือรวมทุก movement ที่บันทึก ไม่ใช่คงเหลือสิ้นเดือนกันยายน
แฟ้มจากออเดอร์ pending จ่ายออกไปบางส่วนได้ จึงกระทบ stock แต่ไม่เป็น paid sales

### ผลสองวิธีตรงกันแปลว่าถูกหรือไม่?

ไม่พอ ต้องตรวจข้อมูลต้นทางกับ SQL อ้างอิงด้วย
หน้า live จึงแสดงความตรงกัน ไม่แสดงป้ายคะแนนความถูกต้องโดยไม่มี ground truth
ในผลบันทึกจึงมีตารางคำตอบอ้างอิงและคะแนนแต่ละวิธีแยกต่างหาก

### Schema มาจากไหน และเป็น WMS จริงหรือยัง?

AI ช่วยสร้าง schema และข้อมูลสังเคราะห์ แล้วขยายจากข้อมูลขายเป็นแบบจำลองรับ–จ่าย
ยังไม่ได้ตรวจเทียบกับ WMS จริง ผลพิสูจน์เฉพาะขั้นตอน Text-to-SQL ในขอบเขตนี้

### ทำไม Rule-based ได้ 6/10 ทั้งที่ชุดพัฒนาได้ 10/10?

ชุดประเมินมีการเรียบเรียงใหม่ 4 ข้อที่กฎไม่ครอบคลุม จึง unmatched/unsupported
ไม่ได้คืน SQL ผิดแล้วนับว่าเป็นคำตอบ และไม่ได้ลบข้อเหล่านั้นออกจากตัวหาร
สิ่งนี้แสดงข้อจำกัดด้านรูปประโยค แต่ยังไม่ใช่ผลสรุปทุกโดเมน

### ทำไม LLM ได้ 10/10 แล้วไม่เลือก LLM ไปเลย?

นี่เป็นเพียงสิบข้อบน schema/ข้อมูลจำลองเดียว LLM ยังมีเวลาเรียกบริการและใช้ Token
การเลือกใช้ต้องพิจารณาขอบเขตจริง จำนวนผู้ใช้ ต้นทุน และความผิดพลาดเพิ่มเติม
ยังไม่ทราบอัตรา quota เป็นเงินบาท จึงไม่รายงาน cost เป็นศูนย์

### ทำไม SQL exact match เป็น 0 ทั้งคู่?

SQL อาจใช้ alias, LIMIT หรือวิธีเขียนต่างกัน แต่คืนค่าตรงกันได้
จึงใช้ Execution Accuracy เป็นหลัก เทียบค่าทั้งตาราง แถวซ้ำ และลำดับเมื่อถาม Top-N

### ระบบตอบจำนวนออเดอร์ยกเลิกได้ไหม?

Schema มีข้อมูลคำนวณได้ แต่ยังไม่เพิ่มกฎภาษาและอยู่นอกห้ารูปแบบของการทดลองนี้
ความพร้อมของข้อมูลกับความครอบคลุมของตัวแปลภาษาเป็นคนละเรื่อง

## การทดลองเปลี่ยนข้อมูล (เสริมถ้าอาจารย์ถาม)

ทำใน **โหมดรันสด** และระบุว่าผลบันทึกเป็นคนละ snapshot

```powershell
.\.venv\Scripts\python.exe -m scripts.local_demo add-sale
```

ถาม `ยอดขายเดือนกันยายน 2569` ใหม่ ต้องได้ **1550.00** เพราะเพิ่ม paid sale `20 × 15`
stock จะไม่ลด เพราะคำสั่งนี้ไม่ได้สร้าง issue นี่เป็นตัวอย่างการแยกการขายกับการจ่ายของ
โหลดข้อมูลต้นทางใหม่เพื่อเห็นออเดอร์ที่เพิ่ม จากนั้นกลับสู่ข้อมูลสังเคราะห์ตั้งต้นด้วย:

```powershell
.\.venv\Scripts\python.exe -m scripts.local_demo reset
```

reset ล้าง/สร้างข้อมูลสังเคราะห์ทั้งห้าตาราง จึงควรทำเฉพาะเมื่อประสงค์กลับชุดเดโมตั้งต้น
การเปลี่ยนข้อมูลนี้ไม่ได้เปลี่ยนรายงานเก่า ซึ่งยังเป็นผลของรอบที่บันทึกไว้

## แผนสำรองเมื่อ API หรือเครือข่ายไม่พร้อม

1. ถ้าเซิร์ฟเวอร์ localhost ยังเปิดได้ ให้เลือก **ผลบันทึก** แล้วเปิดคำถามที่ต้องการ
2. ถ้าเปิดเซิร์ฟเวอร์ไม่ได้ ให้ดับเบิลคลิกไฟล์ `output/presentation/offline-demo.html`
3. พูดว่า "ส่วนนี้เป็นผลจากการรันที่บันทึกไว้เมื่อ..." ตามวันที่บนป้าย
4. ออฟไลน์ปิดโหมด live ใช้ CSS/JS/ผลทดลองที่ฝังในไฟล์ ไม่ต้องใช้ API key หรือฐานข้อมูล
5. ข้อมูลต้นทางจะรวมในไฟล์เฉพาะเมื่อ fingerprint ตรงกับ snapshot ของผลทดลอง

สร้างไฟล์สำรองใหม่ได้ด้วย:

```powershell
.\.venv\Scripts\python.exe -m scripts.build_offline_demo
```

ไฟล์นี้เป็น HTML สำรองที่ตรวจใช้งานได้ ไม่ใช่วิดีโอบันทึกการสาธิต

## ซ้อมสองรอบ

- รอบแรก: ไล่ตามตาราง 7 นาที จับเวลาจริงและหยุดเปิด SQL เมื่อเกินเวลา
- รอบสอง: ใช้ผลบันทึก/ไฟล์ออฟไลน์ทั้งรอบ ให้แน่ใจว่าอธิบายที่มาคำตอบได้แม้ไม่มี API
- ก่อนนำเสนอ: ตรวจ status ฐานข้อมูลและโมเดลบนหน้าแรก แล้วรัน canonical question หนึ่งข้อ
- หยุดเพิ่มฟีเจอร์เมื่อเดโมและคำอธิบายพร้อม ใช้เวลาที่เหลือตรวจความเข้าใจของตัวเอง
